NFL Player Comparison & Ranking ToolAn interactive, multi-position NFL player evaluation tool built with Python, pandas, nflreadpy, and matplotlib. This application enables user-defined metric weighting, standardized Z-score performance indexing, dynamic position filtering, fuzzy player searching, and side-by-side visual analytics.Table of ContentsOverviewKey FeaturesStatistical Formula & MethodologyInstallation & RequirementsUsage GuideVisualizationsDevelopment Iterations & ChangelogOverviewTraditional NFL statistics often evaluate players using single raw volume metrics (e.g., total passing yards) or raw averages that fail to account for context, sample size, or turnover penalties. This tool normalizes metrics across positions using Z-scores derived from 2023 regular-season data loaded via nflreadpy. It allows users to rank Quarterbacks (QB), Running Backs (RB), Wide Receivers (WR), and Tight Ends (TE) using balanced default formulas or custom-weighted criteria.Key FeaturesMulti-Position Normalization: Evaluates QBs, RBs, WRs, and TEs using position-tailored factor dictionaries and minimum play thresholds.Fuzzy & Robust Name Search: Handles input typos (e.g., "jaylen hurts" $\rightarrow$ "Jalen Hurts") and punctuation variations (e.g., "tj watt" $\rightarrow$ "T.J. Watt") using string cleaning and difflib.Interactive Preset & Custom Weighting: Switch between Volume-heavy, Efficiency-heavy, Balanced, or fully customized metric weights (1–5 scale) with built-in overlap warnings.Turnover Penalty Directionality: Automatically flips negative indicators (Interceptions, Fumbles Lost) so higher raw totals reduce composite rankings.Comparative Matplotlib Visualizations: Generates grouped bar charts comparing player Z-scores directly against peers or position baselines.Statistical Formula & Methodology1. Z-Score StandardizationTo compare disparate metrics (such as Passing EPA/play vs. Total Passing Yards) on an identical scale, raw stats ($X$) are transformed into standard deviation units ($Z$):$$Z = \left(\frac{X - \mu}{\sigma}\right) \times D$$Where:$X$ = Player's raw stat$\mu$ = Qualified position mean$\sigma$ = Qualified position standard deviation$D$ = Direction multiplier ($+1.0$ for positive metrics, $-1.0$ for negative metrics like INTs or Fumbles)2. Weighted Composite IndexPlayer rankings are generated using the weighted mean of individual metric Z-scores:$$\text{Composite Score} = \frac{\sum (Z_i \times w_i)}{\sum w_i}$$Where $Z_i$ is the standardized metric score and $w_i$ is the assigned weight ($1 \le w_i \le 5$).3.
